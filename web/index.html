How do I get a key?

  1. In PagerDuty, open Integrations → API Access Keys (these are account-level keys; do not use a User API token from your profile).
  2. Create a new key and tick Read-only.
  3. Paste it here.
The key needs access to users, teams, schedules, on-calls and (for engaged time) Analytics. If your plan does not include Analytics, you'll be told before running.
Advanced: API pacing & retries
Safe defaults. Calls are spaced out and retried with increasing waits; the tool also honors PagerDuty's own wait time.
